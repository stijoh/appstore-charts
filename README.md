# Appstore Charts

Helm charts for the Bitpipe Kubernetes App Store.

## Available Charts

- postgresql - PostgreSQL database
- mongodb - MongoDB database (coming soon)
- minio - MinIO object storage (coming soon)
- openbao - OpenBao secrets management (coming soon)
- valkey - Valkey in-memory cache (coming soon)

## Usage

These charts are automatically synced by the appstore-operator.
